## `Draw`

Shows terrain name and size; label options; per layer a count (boxes; meshes and triangles), a show checkbox, a draw-distance field applied to every debug object, and a "dump debug meshes" button that destroys that layer's geometry. The cell layer also shows the occupancy colour legend (0…block size triangles in 10 steps, colour `(2f, 2(1−f), 0.2, 0.7)`) and the generation radius.

After the window: when labels are on, label every event box and collision mesh within draw distance of the camera.

## Geometry (created on first enable)

- **Event box** — its 8 debug corners as 12 triangles plus 12 edges, material: solid box, virtual box with a script handler ("used"), or virtual box without ("unused"); rendering distance 200.
- **Collision mesh** — one triangle list of its triangles relative to its position, infinite bounds.
- **Cells** — generated by the collision system inside a box of ± radius around the character (all heights), coloured by 101 generated materials (`mat-coll-dbg-0…100`, colour by occupancy, alpha-blended, no depth write, depth bias 3, over a tile texture). Out of memory → console error and cleanup.

## Labels

Centred at the object's projected position (only if in front of the camera), semi-transparent background. Event box: `EVENTBOX`, event name, instance, handler id, filter (avatar, truck, truck wheels, airplane, boat); only virtual boxes with an event source are labelled. Mesh: `COLLMESH`, mesh name, ground model (or "(multiple)"), optionally source file.
