# source/version_info — build identity

First chapter in build order: depends on nothing, read by the log header, the About box, the mod cache and the multiplayer handshake.

It exists as a separate library so the always-changing version strings can be regenerated on every build without invalidating the rest of the program. A rebuild can inline these as constants generated by its own build tool.

| Twin | Role |
|---|---|
| [`RoRVersion.h`](RoRVersion.h.md) | Declares the four version strings |
| [`RoRVersion.cpp.in`](RoRVersion.cpp.in.md) | Template + the rule deriving `YYYY.MM[-dev-<hash>[-dirty]]` |

Skipped: `CMakeLists.txt` (build wiring, folded into the twin above); `RoRVersionDef.h.in` (Windows resource version, described in the `.cpp.in` twin's notes).
